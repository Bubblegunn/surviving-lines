# Roadmap

Three next steps, in no particular order. Open an issue if you want to take one.

- `--by name` to merge identities without a `.mailmap`
- A `--since/--until` window for the blame side (blame at a past ref is already possible with `--ref`)
- A GitHub Action that comments a surviving-lines table on pull requests

Things deliberately not planned: anything that needs a server, a hosted account, or reads code content.
