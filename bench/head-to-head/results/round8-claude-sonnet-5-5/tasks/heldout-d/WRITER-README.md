# Held-out task set d (d1 to d5)

Each task: a public repo pinned to the last commit before 2026-01-01, then synthetic commits with fixed authors, e-mails and dates (all in 2026). `dN/build-fixture.sh <dest>` rebuilds it (same HEAD sha every time), `dN/truth.py <fixture>` prints the ground truth with plain git, `truth.txt` is that output, `criteria.md` has 5 outcome criteria, `prompt.txt` is the user question.
Shared truth method: `git blame -w -M -C --line-porcelain` per in-scope file at HEAD, author field only, `--ignore-revs-file` for mechanical commits, identities merged through `.mailmap`/`git check-mailmap`, same e-mail (case-insensitive), same multi-word name, and explicit aliases where stated; bot lines are not ranked; shares use human live lines as the denominator.

**d1: cJSON (C), https://github.com/DaveGamble/cJSON, pin c859b25da02955fef659d658b8f324b5cde87be3.** Scope: cJSON.c and cJSON.h. Hazards: a whitespace-only clang-format commit (named in a later `.git-blame-ignore-revs`), one contributor (Tomás Ibarra) under two names and e-mails whose link is only a Signed-off-by trailer, a partial `.mailmap`, an experiment added then reverted, a release bot that rewrites license headers and the version line. Conventions: blame -w with the repo's ignore file, alias for the Ibarra pair, bot lines excluded from the denominator.

**d2: pflag (Go), https://github.com/spf13/pflag, pin 6fcfbc9910e1af538fde31db820be7d1bec231e4.** Scope: all `*.go` (tests included). Hazards: a vendored `vendor/` tree and a generated `zz_generated_flags.go` committed by a person, a dependabot go.mod/go.sum commit, a squash-merged PR whose co-authors exist only in trailers, a tree-wide `interface{}` to `any` rewrite (not in any ignore file), real duplicate identities. Conventions: vendor/ and "Code generated" files excluded, rewrite commit ignored by subject, trailers not credited. The prompt asks about concentration, so the truth lists top-3 share and people needed for 50%.

**d3: rack-attack (Ruby), https://github.com/rack/rack-attack, pin 77195a5be6f69645aef0f62c1c54f13998d3a08d.** Scope: `lib/rack/attack/store_proxy/` (about 346 live lines; a "who do I ask" question). Hazards: the maintainer committed three contributors' patches (author differs from committer), methods extracted into a new file (needs `-C`), a rubocop bot autocorrect that rewrites quotes and hash syntax, a file added and deleted, the maintainer under several names and addresses with no `.mailmap`. Conventions: author not committer, blame -M -C, bot commit ignored by subject so lines go back to the humans.

**d4: walkdir (Rust), https://github.com/BurntSushi/walkdir, pin 6fd031c82ba5a4204b4ce6eae73dacb00dc072ec.** Scope: `src/` (bus-factor question). Hazards: a bystander commit that converts `src/error.rs` from LF to CRLF (only `-w` sees through it), a generated 880-line errno table, code added and then deleted, one contributor with two spellings of one e-mail that differ only in case, a real duplicate (nivkner). Conventions: blame -w, "@generated" files excluded, bus factor = fewest people covering at least 50% of live lines.

**d5: phpdotenv (PHP), https://github.com/vlucas/phpdotenv, pin 2af27192fc6c6bf7c05ef26e67d54afe9a0c39e1.** Scope: `src/Parser/` (reviewer question). Hazards: the maintainer under several e-mail addresses with one name, StyleCI style-only commits (one synthetic by "StyleCI Bot", many real ones pushed through the maintainer's account), a pure rename that moves `src/Util/Regex.php` into the directory, add/revert/re-land by revert-of-revert, a feature branch merged with a merge commit. Conventions: all "Apply fixes from StyleCI" commits ignored by subject, rename followed, re-landed code belongs to the re-landing author, merge commits own nothing.
