## 🔍 Code History: `lib/index.js`

### Quick Context
> This is the core of the `cors` middleware. It handles origin matching, preflight responses, and header application. Troy Goode wrote it in 2013 and it has had about 62 commits since.

### Decision Timeline
- **2013-01 to 2013-10:** Troy Goode wrote the original file. Contributors added early-`Origin` checks (Simon Mansfield), a callback form for `origin` (Eric di Domenico), and Connect support without Express (Mathias Buus).
- **2014:** Troy added `Access-Control-Expose-Headers` and Express 4 support. Other contributors added `PATCH` to the default methods (Typicode), uppercase normalization of method names (Shane Tomlinson), and a fix so the `origin` callback isn't overridden (Alberto Leal). Igor Soarez added `Vary: Origin`, and Troy then moved it to the `vary` module.
- **2015:** Raymond Feng removed a closure in `applyHeaders`. Alejandro Caravaca Puchades added RegExp and array values for `origin`. max.laverse let preflight requests pass through to `next()`, and DracoBlue added exposed headers to the OPTIONS response. Troy moved linting to ESLint.
- **2016 to 2017:** Troy's 2.8.0 release (2016-08). Douglas Christopher Wilson then made the `Vary` header handling correct for regex origins and dynamic `allowedHeaders`. He also fixed a missing `methods` option. Benjamin Eidelman added a Safari preflight workaround.
- **2018 to 2021:** Tom Arad fixed `maxAge: 0`, and LuisEGR removed unused parameters in a lint pass.
- **2026-04:** Two recent commits were mostly cosmetic.

  - **`62628c0`**, a reformat to 4-space indent and double quotes, is credited to Fiona Formatter.
