## History

- **Jan–Mar 2013, creation:** Troy Goode made the first commit on 2013-01-30. In the first weeks the file got case-insensitive header lookup, `origin: false` to disable CORS, and lint cleanup. Damien Klinnert's change to send `Access-Control-Allow-Methods` only on OPTIONS requests landed in March.
- **Apr–Oct 2013, early features:**
  - Simon Mansfield added the `Origin` undefined check and moved the credentials header.
  - Eric di Domenico allowed `origin` to be a callback.
  - Mathias Buus made it work with plain Connect, without Express.
  - Goode released v2.1.0 with Connect support.
- **2014, Express 4 and the `Vary` header:**
  - Typicode added `PATCH` to the default methods.
  - Alberto Leal fixed the `origin` callback being overridden.
  - Shane Tomlinson normalized method names to uppercase.
  - Goode added `Access-Control-Expose-Headers` and Express 4 support.
  - Igor Soarez added `Vary: Origin`, and Goode switched it to the `vary` module.
- **2015, options and performance:**
  - Raymond Feng optimized `applyHeaders`.
  - Eran Tiktin fixed `Vary` being sent for `*`.
  - max.laverse added a preflight pass-through to `next()`.
  - DracoBlue added exposed headers to OPTIONS responses.
  - Alejandro Caravaca Puchades (also committing as alex94puchades) added regexp and array `origin` matching.
  - Goode moved the project to ESLint.
  - jordandenison fixed strict-mode handling of non-object options.
- **2016–2017, maintenance:**
  - Hannah Wolfe named the middleware function.
  - Saad Tazi fixed an error with frozen options.
  - Tomek Kopczuk added `Vary: Origin` for regexp origins.
  - Douglas Christopher Wilson did several fixes: `Vary: Access-Control-Request-Headers`, the missing-`methods` error, and lint work.
  - Benjamin Eidelman added a Safari preflight workaround.
  - Chima Alaebo removed an unreachable branch.
- **2018–2021, small fixes:** Tom Arad fixed `maxAge: 0` in 2018. LuisEGR removed unused parameters in 2021.
- **2026:** Goode's "annotate handlers" commit (April 10) was followed by Fiona Formatter's reformat to 4-space indent and double quotes (April 12).
