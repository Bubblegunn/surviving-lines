`lib/index.js` is the core of the `cors` package. Troy Goode created it and still owns most of it. Other contributors added individual features and fixes, and a recent reformat now shows up as a large block of lines in blame.

**Who shaped it**

- **Troy Goode** is the author and main maintainer. He made the first commit on 2013-01-30 and 29 of the 56 file-history commits. His work includes:
  - the core request flow and case-insensitive header lookup;
  - `origin: false` disabling CORS;
  - pausing and resuming the request for async middleware;
  - `Access-Control-Expose-Headers`;
  - Express 4 and non-Express (Connect) support;
  - the move to the `vary` module and the switch to ESLint.
- **2013, early contributors.**
  - Simon Mansfield added the early check for a missing `Origin` header and sent the credentials header on non-OPTIONS requests.
  - Damien Klinnert limited `Access-Control-Allow-Methods` to preflight responses.
  - Eric di Domenico let `origin` be a callback.
  - Mathias Buus switched to non-Express request and response APIs, which enabled Connect use.
- **2014–2015, features and fixes.**
  - Typicode added PATCH to the default methods.
  - Alberto Leal fixed the `origin` callback being overridden.
  - Shane Tomlinson made method names compare in uppercase.
  - Igor Soarez added `Vary: Origin` for specific origins.
  - Eran Tiktin stopped `Vary: Origin` being added for `*`.
  - Raymond Feng removed the closure in `applyHeaders`.
  - max.laverse let the preflight request pass through to `next()`.
  - DracoBlue added exposed headers to OPTIONS responses.
  - Alejandro Caravaca Puchades (also committing as alex94puchades) added RegExp and array support for `options.origin`.
  - jordandenison made non-object options work in strict mode.
- **2016–2018, maintenance.**
  - Hannah Wolfe named the anonymous middleware function.
  - Saad Tazi fixed frozen options.
  - Tomek Kopczuk added `Vary: Origin` for regex origins.
  - Benjamin Eidelman worked around a Safari preflight bug.
  - Tom Arad fixed `maxAge: 0`.
  - Douglas Christopher Wilson did the following:
    - `Vary: Access-Control-Request-Headers` for dynamic `allowedHeaders`;
    - a fix for a missing `methods` option in the options delegate;
    - ESLint and lint cleanups.
  - Chima Alaebo removed an unreachable branch.
- **2021–2026.** LuisEGR removed unused function parameters (2021). Troy Goode committed "annotate handlers" (2026-04-10). Fiona Formatter reformatted the file to 4-space indent and double quotes (2026-04-12).
