# Reproduce round13-claude-sonnet-5-5

Run from a clone at or after the commit that holds this folder. Needs: the `claude` CLI (2.1.308), a Claude Code login (this round used the owner's subscription login through a wrapper; an API key also works but changes the cost figures), git, python3, node. Do not run the Vaara plugin; run rivals only from `git archive` copies at the commits in `arms.json`. All work directories must be under `/private/tmp` (or any folder outside your home directory): a working directory below the home directory loads your `~/.claude/CLAUDE.md` into every arm.

1. **Fixtures.** Public: `bash bench/head-to-head/build-fixture.sh <fixtures>` (also `tasks/public/build-fixture.sh`); its ground truth is `tasks/public/truth/`. Sealed z: `bash tasks/sealed-z/z<n>/build-fixture.sh <dir>` for n = 1..5; the ground truth is `tasks/sealed-z/z<n>/truth.txt` (script `truth.py`, criteria in `criteria.md`). **Published form of the scripts:** contributor e-mail addresses are replaced by their SHA-256 and the scripts compare hashes read from the pinned clone at run time (`tasks/sealed-z/ADDRESSES-NOTE.md`). Built from these scripts the fixtures have the HEAD shas that were run and graded, and `truth.py` reproduces `truth.txt` byte for byte (verified 2026-10-24). The pre-hash originals are on the local branch `heldout-2026-10-z` (`93fb942`, not pushed).
2. **Arms.** `ours`: `git archive 8af57f4 | tar -x -C <ours-src>`. Rivals: see `arms.json`. Export `OURS_DIR PP_DIR HIST_DIR BF_DIR`, `MODEL=claude-sonnet-5-5`, `TASKS_FILE=<this folder>/tasks/final-tasks.json`, `PARALLEL=3`.
3. **Rerun any cell.** `bash bench/head-to-head/run.sh <out> <fixtures> <arm> <task> <run-number>` (one cell), or `PARALLEL=3 bash bench/head-to-head/run-gate.sh <out> tasks/final-tasks.json <fixtures> <arms,comma> <run-number> [task,comma]`. The driver scripts of this round are in `driver/` (`drive.sh`, `p-runs.sh`, `p-grade.sh`, `p-f6.sh`, `p-f9.sh`, `env.sh`).
4. **Regrade.** `python3 -I bench/head-to-head/gate-grade5.py <out> tasks/final-tasks.json <truth-dir> --cells <task>-<n>` (all arms of a task and run together in a shuffled order, five calls per cell, reason before verdict; run it again to re-ask only the calls whose reply does not parse; `--reverse` for criteria still `err`). The prompt of every cell is `grades/<set>/<cell>.in`; the `<truth-dir>` holds one `<fixture>.txt` per fixture (`tasks/public/truth/`, `tasks/sealed-z/truth/`).
5. **Rescore.** `python3 -I score.py` prints `SUMMARY.md`; `python3 -I score.py --check` fails on any difference. It reads only files in this folder.
6. **Checks.** `python3 -I check-order.py`, `python3 -I check-isolation.py`, `python3 -I ../../scrub.py --check .`, `shasum -a 256 -c SHA256SUMS`.

**Cost and time.** The dollar figures per category and payer are in `SUMMARY.md` (section Round cost). A rerun of the 90 sealed and 189 public cells with their grading costs the amounts shown for the `runs-` and `grade-` rows at list price; on a subscription login the CLI reports the same list-price estimate. Wall time is in `SUMMARY.md` (cost per arm) and `drive.log.txt`.

**What differs on a rerun.** Model output varies run to run. The F6 audit (about 10% of all cells graded again, and run again) is in `SUMMARY.md`: it gives the observed agreement rate and the cells that moved by more than one point. Read it before expecting a rerun to reproduce a single cell.
