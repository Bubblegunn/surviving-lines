# Sealed set z

Five tasks, one per ecosystem (Python, Go, Zig, Ruby, PHP). Each task directory has `prompt.txt`, `build-fixture.sh <dest>`, `truth.py <fixture>` (run as `python3 -I truth.py <fixture>`), `truth.txt` and `criteria.md`. Every fixture is a fresh clone pinned to one upstream commit, with remote, tags and other branches removed, plus synthetic commits with fixed names, e-mails and dates on branch `main`. Two builds give the same HEAD sha (checked). The upstream shas are pinned; the synthetic HEAD shas are listed per task.

**z1 - tartley/colorama, pinned 841634ed2a0da5d5ac2d867db533da8131266cb2, fixture HEAD 475b3d409fa353502cf44201a90eb42ebb62b822.** Question: who wrote the Python code that survives, and the exposure if the top two leave. Hazards: the real history already has one person under four addresses (Arnon Yaari / wiggin15) and several others; synthetic: a quote-style formatter commit over every .py file, a pre-commit.ci bot rewrite (printf to f-strings), a 1,100-line vendored module added by a human, a feature that was reverted and then re-applied by the reverter ("Reapply"), a patch authored by one person and committed by another, the test directory moved out of the package, a dependabot bump. Conventions: scope is tracked *.py minus `colorama/_vendor/`; `git blame -w -M -C` with an ignore-revs file for the formatter and bot commits; lines of the Reapply commit go to the author of the original commit; author, not committer, owns a line; identities merged by an alias table; bots own nothing; left = no authored commit in the 365 days before 2026-10-15; bus factor = fewest people reaching 50% of surviving lines.

**z2 - google/uuid, pinned 2d3c2a9cc518326daf99a383f07c4d3c44317e4d, fixture HEAD 08af9eef4787055aa3b4035e715ecb3421a9e920.** Question: who should review time.go, version7.go and the SQL code, and are the authors around. Hazards: real aliases (Paul Borman under five names/addresses); synthetic: LF-to-CRLF commit on two files, a generated Go file and a vendored package added by a human, NodeID functions moved to a new file, sql.go renamed to database_sql.go, one new contributor under three identities with a .mailmap that covers only two, two commits of ULID work reverted and never re-applied, a patch authored by Mei Chen and committed by the maintainer, a commit with author date 1970-01-01, renovate bot commits. Conventions: tracked *.go minus vendor/ and files marked "DO NOT EDIT"; `git blame -w -M -C` (no ignore file needed: -w absorbs the CRLF commit, -C follows the move, git follows the rename); author owns; reverted work leaves no lines; alias table, .mailmap not trusted; activity time is the committer date (the 1970 author date is a clock error); left = no commit in the 365 days before 2026-10-15.
