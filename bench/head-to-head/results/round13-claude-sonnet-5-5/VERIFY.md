# Verify round13-claude-sonnet-5-5 (checklist for another LLM or a person)

Run all commands from inside this folder (`bench/head-to-head/results/round13-claude-sonnet-5-5`). No network and no model calls are needed.

1. **Protocol was frozen before the runs.** `git log --format='%h %cI %s' -- docs/HEAD-TO-HEAD.md` from the repository root: `8345b3d` (final measurement protocol) precedes this folder's commit and `summary-meta.json` records its commit time. `python3 -I check-order.py` prints the earliest timestamp in the traces of all cells (scored runs, F6 re-runs, F9) and exits 0 only if it is not before the protocol commit time. Proves no scored run started before the freeze. `PROTOCOL.md` holds the frozen text verbatim, with the commit list.
2. **No reused cells.** The protocol says all cells are new and this folder has no `reused.json`; `SUMMARY.md` has no `R` marks. `drive.log.txt` shows every run started after the protocol time (`FINAL DRIVE START`).
3. **Scores recompute.** `python3 -I score.py --check` prints "score.py --check: SUMMARY.md matches the recomputation". Proves every table, Rule A, Rule B, Rule B', bootstrap interval, grader reliability, hook table, F6 and F9 table, and the cost tables come from `grades/`, `f6/`, `f9/`, `runs/*/cost.json`, `runs/*/trace.jsonl.gz` and `cost-ledger.tsv`. The script also re-draws the F6 sample from the graded cells and prints whether it equals the recorded sample.
4. **Five votes, reason first.** In `SUMMARY.md` (Grader reliability, per set) the number of votes without a result, the share of verdicts on which all five votes agree, and the share of grader replies that wrote `reason` before `pass`. Open one `grades/<set>/<cell>.call1..5.out`: five separate grader sessions.
5. **Grading was blind and joint.** Open one `grades/<set>/<cell>.in` (exact grader prompt, answers labelled in a shuffled order, plugin names hidden), `<cell>.labels.json`, `<cell>.call1..5.out`. `grades/<set>/logs/` holds the per-cell grading logs including parse failures and re-asks; a reply that failed to parse was overwritten by its re-ask and is not kept (see `SUMMARY.md`, cells set aside, re-asks and driver events).
6. **Hook block rate.** `SUMMARY.md` section Hook: how many `ours` first answers were blocked by the Stop hook (the trace holds the text "Check your answer against surviving-lines") and the mean score of blocked and unblocked cells. To see one: `zcat runs/<set>/<task>/ours/<n>/trace.jsonl.gz | grep -c 'Check your answer against surviving-lines'`.
7. **Isolation.** `python3 -I check-isolation.py` reads the `init` event of every trace and exits 0 only if no run directory was below the home directory (every `cwd` starts with `/private/tmp/`) and no event reports an API key as the auth source.
8. **Redaction holds.** `python3 -I ../../scrub.py --check .` exits 0 (it reads the `.gz` traces too). Addresses, keys, tokens and home paths are replaced by placeholders (`<email redacted>`, `<secret redacted>`, `<home>`, `<scratch>`, `<tmp>`); traces drop the redundant `wire_tool_inputs` key. Paths under `/private/tmp/r13/` are the run path and stay.
9. **Sealed set writer did not see the code.** `tasks/README.md` and `tasks/sealed-z/writer.prompt.md`: what the writer was shown, and the controller's disclosed exposure. The sealed set is now used and published here.
10. **Development gates.** `development/README.md`: protocol commits, the analysis outputs, per-task tables and task files of gates 1 and 2 (transcripts not included). Gate 1 was the product before the fixes; both are reported.
11. **Folder is unchanged.** `shasum -a 256 -c SHA256SUMS` prints OK for every file.
12. **The claim does not exceed the tables.** `SUMMARY.md` states per set which of I1 and I2 passed (table "Verdicts (computed)"); "first" is never claimed beyond what those lines show, and `score.py --check` fails if the result sentence uses "first" or "highest total" without a passing I1 on the complete SEALED z set. PUBLIC is a development-seen set.
