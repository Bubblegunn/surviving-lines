Each task directory has prompt.txt, build-fixture.sh <dest> (clone, pin, synthetic commits with fixed names/emails/dates, clean `master`, no remote), truth.py <fixture> (plain git blame ground truth, conventions in the header comment), truth.txt (its output on a verified build) and criteria.md (5 outcome criteria).

Truth: *.go outside vendor/, blame -w -M -C, mechanical-rewrite commits (synthetic go fix and the two real gofmt commits) passed as ignore-revs, bot lines dropped from the denominator, Marcus identities merged by email alias.
