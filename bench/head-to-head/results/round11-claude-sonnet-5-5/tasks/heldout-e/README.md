# Held-out task set e (e1–e5)

Problem under test: "who wrote the code that is still in this repo" — surviving lines, not commit counts; no credit for formatter commits and bots; one person counted once. Each task clones a public repo at a pinned commit, adds synthetic commits (fixed names, emails, dates) and has a plain-git ground truth (`python3 -I eN/truth.py <fixture>`; saved in `eN/truth.txt`). Fixtures build with `eN/build-fixture.sh <dest>`; two builds give the same HEAD sha. Common truth conventions: non-blank lines; `git blame --line-porcelain -w -M -C`; author (not committer); identities merged when they share an email, a GitHub noreply login or a multi-word name (case/diacritics ignored), after `.mailmap`; bots reported separately and outside the share denominator; lines git cannot hand back from an ignored commit are "unattributable" and leave the denominator. Fixture HEAD dates (as-of dates) are the dates of the last synthetic commits.
