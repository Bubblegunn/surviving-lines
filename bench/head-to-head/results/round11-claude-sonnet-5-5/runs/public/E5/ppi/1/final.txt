## Code History: `lib/index.js`

### Quick Context
> This is the `cors` middleware core. Troy Goode wrote it in January 2013. Most of it is still his, with a 2026 formatting pass on top.

### Decision Timeline
- **2013-01-30, Troy Goode:** first commit. Same day: case-insensitive header lookup, and `origin: false` disables CORS.
- **2013-02 to 2013-04, Troy Goode, Damien Klinnert, Simon Mansfield:**
  - Request pause/resume for async middleware.
  - Preflight-only headers, per the CORS spec.
  - `HEAD` added to the default methods.
  - Checks for a missing `Origin` header.
  - Credentials header moved.
- **2013-10, Eric di Domenico, Mathias Buus, Troy Goode:** `origin` can be a callback. Support for Connect without Express (v2.1.0).
- **2014, Troy Goode and others:**
  - `Access-Control-Expose-Headers`.
  - `PATCH` added to the default methods (Typicode).
  - Uppercase method normalization (Shane Tomlinson).
  - Express 4 support (v2.3.2, v2.4.0).
  - `Vary: Origin` (Igor Soarez), then the `vary` module.
- **2015:**
  - Raymond Feng removed a closure in `applyHeaders`.
